# Titanic: предсказание выживания (scikit-learn)

Учебный ML-проект. Модель предсказывает, выжил ли пассажир Титаника, по полу, классу, возрасту, цене билета, семье и титулу из имени.


## Результат

| Метрика | Значение |
|---|---|
| Базовая линия («все погибли») | 0.615 |
| Кросс-валидация, accuracy (5 частей, учебная часть) | 0.824 ± 0.024 |
| Кросс-валидация, AUC | 0.883 |
| Тест (179 пассажиров), accuracy | 0.844 |
| Тест, AUC | 0.858 |

Модель: случайный лес (300 деревьев, `min_samples_leaf=5`) в одном `Pipeline` вместе с созданием признаков и подготовкой данных.

> Тест маленький (179 человек), его точность «плавает» примерно на ±0.03. Опираться лучше на кросс-валидацию.

## Как запустить

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
```

1. Положи файл `titanic.csv` (Kaggle, 891 строка) в папку `data/`. В репозиторий он не входит.
2. Обучение (из корня проекта): `python -m src.train`. Создаёт `models/model.joblib` и `models/metrics.json`.
3. Пример предсказания: `python -m src.predict`.
4. Тесты: `pytest`.

## Структура

```
src/features.py   создание признаков (Title, FamilySize)
src/model.py      сборка Pipeline
src/train.py      обучение, кросс-валидация, тест, сохранение модели
src/predict.py    загрузка модели и предсказание для одного пассажира
tests/            быстрые тесты на выдуманных данных
notebooks/        уроки 1–8: путь от первой модели до KMeans
```

## Важное

- Модель сохранена через `joblib`. Загружать её нужно с той же версией scikit-learn (она записана в `models/metrics.json`) и из корня проекта: внутри файла хранится ссылка на `src.features.add_features`.
- В боевую модель данные подаются «сырыми» (имя, пол, возраст...). Признаки считаются внутри `Pipeline`, поэтому при обучении и предсказании они всегда одинаковые.
